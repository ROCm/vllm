# Golden — sliding window

Best measured result for the sliding-window configurations of `shapes.csv`
(Gemma 3, Gemma 4, PaliGemma 2), fp16 and bf16, both query-token counts.
Replace only when a run beats this one, and say in the commit message what
changed to earn it.

| host | Radeon 8060S (gfx1151), batch = 1, HND, block size 16 |

Past S = window every context reads the same bytes, so the plateau is the
number that matters.  Its bytes are the window's KV, 0.5-16 MiB, where even a
pure stream stays under roof (`ceiling`).
